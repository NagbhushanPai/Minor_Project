🤖 RAG Q&A Application - SIMPLE INSTRUCTIONS
==============================================

📋 HOW TO RUN:
1. Double-click "START_HERE.bat"
2. Wait for "Local URL: http://localhost:8502" message
3. Open your browser to http://localhost:8502
4. Ask questions about your Bhagavad Gita data!

📁 YOUR DATA:
- File: bhagavad_gita_verses.csv
- Contains: 641 verses from all 18 chapters
- Translations in English

💡 EXAMPLE QUESTIONS:
- "What is the main message of Chapter 2?"
- "Tell me about dharma in the Bhagavad Gita"
- "What does Krishna say about action and duty?"
- "Explain the concept of karma yoga"

🔧 IF YOU GET ERRORS:
1. Make sure Python is installed
2. Run setup.bat first (if it exists)
3. Or manually install: pip install streamlit langchain
